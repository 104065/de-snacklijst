# De snacklijst

Oefenproject voor GitHub flow met PhpStorm.

Jullie werken met z'n tweeën. Spreek af wie **Mayo** is en wie **Ketchup**.

- Mayo vult de eerste snack in `index.php` in en merget als eerste.
- Ketchup vult de tweede snack in en merget als tweede.

Volg de opdrachten in `opdrachtkaarten-github-flow.pdf`.
